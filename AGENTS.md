# User communication preference

The user explicitly asks for explanations at a Primary 4 reading level. Use plain words, short sentences, small numbered steps, and familiar examples. Explain technical terms when needed. Clearly separate what the project currently does from recommendations and work not yet implemented. Stay respectful and do not talk down to the user.

This preference supplements the working rules in the parent AGENTS.md.

# APK build permission

Build an Android APK only when the user explicitly asks for an APK build. Updating or deploying web/backend code, syncing Git, or changing mobile source does not authorise an APK build.
